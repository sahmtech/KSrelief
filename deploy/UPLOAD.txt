Esghaa — Cloudways Upload Guide
=================================

1) Upload esghaa-deploy.zip to ~/public_html and extract:
   unzip -o esghaa-deploy.zip -d ~/public_html

2) Set Cloudways Webroot to: public_html/public   <<< CRITICAL (fixes icons + menus)

   Cloudways → Application → Application Settings → General
   → Web Application Settings → Set "public" as webroot folder
   OR point document root to: .../public_html/public

   If webroot is public_html (parent folder), CSS may load but:
   - Icons break (font files 404)
   - JavaScript won't load (menus/dropdowns dead)

3) PHP version: 8.2 or 8.3

4) Create .env on server:
   cp .env.cloudways.example .env
   nano .env
   (fill DB_* and APP_URL, then save)

5) Install PHP packages (REQUIRED — zip does not include vendor/):
   chmod +x deploy/fix-vendor.sh
   bash deploy/fix-vendor.sh

   If the site shows "HasApiTokens not found", run fix-vendor.sh again.

6) Optional full post-deploy (includes db:seed — skip on live DB if not needed):
   bash deploy/post-deploy.sh

7) Login:
   Email: superadmin@ksrelife.com
   Password: ks123456relife

Notes:
- Do NOT upload vendor/ or node_modules/ — composer installs vendor on server.
- public/build/ is already included in the zip (CSS/JS ready).
- You do NOT need npm on the server. Run "npm run build" only on your PC inside deploy/package.ps1.
- If you use "git pull" on the server, PHP/code updates but NOT CSS/JS — either run deploy/package.ps1
  locally and upload esghaa-deploy.zip, or upload only the public/ folder from that zip.
- Optional after zip deploy (no seed on production if DB already live):
  export COMPOSER_CACHE_DIR=/tmp/composer-cache && mkdir -p /tmp/composer-cache
  composer install --no-dev && php artisan migrate --force && php artisan config:cache && php artisan view:cache

- If "Class Laravel\\Sanctum\\Sanctum not found" during composer install:
  export COMPOSER_CACHE_DIR=/tmp/composer-cache && mkdir -p /tmp/composer-cache
  composer require laravel/sanctum:^4.3 --no-dev --optimize-autoloader
  (Then upload latest zip with fixed config/sanctum.php, or git pull that file.)
